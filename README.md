# multi-player-app

Workspace for sibling multiplayer platform projects.

## Bootstrap

For any workspace-scoped prompt, read:

1. `AGENTS.md`
2. `AI_PERSONA.md`
3. `docs/README.md`
4. `docs/workflow.md`
5. relevant workspace standards in `docs/`
6. target project `AGENTS.md`, `README.md`, `AI_PERSONA.md`, `context/`, and local docs

Workspace docs own shared rules. Project docs specialize them for local commands, paths, APIs, validators, and narrow exceptions.

## Projects

- `multi-player-app-ai/`: Go and C multiplayer backend reference project.
- `mp-cache/`: C17 cache server for Unix-socket local deployment and controlled S2S access.
- `multi-player-app-ai/native/mp_logger/`: standalone C logging library embedded by the backend.
